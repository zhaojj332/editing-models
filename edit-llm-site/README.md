# 高等教育出版社智能审校产品体系

基于 Vue 3 重新开发的编辑大模型网站，采用淡蓝色主题和圆滑组件设计风格。

## 技术栈

- Vue 3 (Composition API)
- Vue Router 4
- Vite 7

## 设计特点

- **淡蓝色主题**：以 #5eb3e8 为主色的清新配色
- **圆滑组件**：12px-32px 圆角，胶囊形按钮
- **现代布局**：响应式设计，卡片式内容展示

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 预览

```bash
npm run preview
```
